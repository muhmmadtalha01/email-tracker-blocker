# Email Tracker Blocker

A privacy-focused Chrome extension that detects and blocks hidden tracking pixels in emails and webpages to protect user data.

## Features
- Blocks hidden 1x1 tracking pixels.
- Shows a Privacy Score (A to F) for every website.
- Dark mode support.
- Pro version available for unlimited blocking.
